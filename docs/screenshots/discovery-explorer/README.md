Captures du paquet macOS arm64 avec une base de démonstration isolée, sans jeton TMDB. Les images affichées étaient présentes dans le cache local. Les largeurs indiquées sont celles de la fenêtre.

Pour vérifier au clavier, utiliser **Tab** pour atteindre le groupe des modes, puis les **flèches** pour changer de piste. Utiliser **Entrée** pour lancer l’exploration et ouvrir un synopsis. Enregistrer un film « À voir un jour », passer dans « Ma collection », puis revenir dans Découvertes. Les mêmes films doivent rester affichés jusqu’à « Explorer encore ».
