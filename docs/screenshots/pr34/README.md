# Sélection avant et après

**Audit.** La carte affichait la première raison brute du moteur, parfois une phrase générique, puis reléguait les autres dans les détails. Le renderer reçoit les motifs calculés et les avertissements, les genres, pays, réalisateurs, mots-clés, réputations et synopsis disponibles. Il ne reçoit pas de preuve suffisante pour attribuer un goût à un réalisateur ou donner un pourcentage de compatibilité.

**Présentation.** Une ligne courte privilégie les préférences explicitement signalées par le moteur, ses indices positifs non contredits ou la réputation déjà retenue. En l’absence d’un tel motif, elle propose une description de genre documentée ou laisse la ligne vide. Informations réunit les données de la fiche, le synopsis disponible, les motifs, les avertissements et les liens existants.

**Actions.** Dans Sélection, Envie de voir utilise l’intention À voir un jour, et Peut-être ce soir utilise Pour ce soir. Les états affichés, la sauvegarde et les erreurs suivent le parcours existant. Pas ce soir continue de masquer temporairement un film, avec annulation. Pas pour moi et Déjà vu gardent leurs effets sur les sélections futures.
